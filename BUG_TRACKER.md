## Detailed Root Cause Analysis & Fixes

### BUG-001: Lookbook Editorial Dead Slugs
- **Symptoms:** Clicking "Inspect Look" in the homepage lookbook navigated users to `/product/chanderi-silk-festive-saree`, displaying a "Piece Not Found" screen.
- **Root Cause:** The database seed script had standardized product slugs to match artisan titles, but the frontend lookbook had retained temporary placeholder slugs.
- **Resolution:** Updated `src/components/storefront/CuratedLookbookSection.tsx` lines 14-22 with live database slugs:
  ```typescript
  href: '/product/chanderi-silk-embroidered-anarkali-robe',
  secondaryHref: '/product/solstice-handwoven-bandhej-viscose-saree'
  ```
- **Verification:** Verified via Puppeteer headless browser (`verify-complete-marketplace.mjs` Test 2). Result: HTTP 200 OK, full PDP loaded with title, imagery, and variant selectors.

### BUG-003: Search Query Parameter Harmonization
- **Symptoms:** Typing a query in the top search bar and pressing Enter loaded `/shop?search=silk`, but the catalog view was filtering on `searchParams.get('q')`, failing to filter the product list.
- **Root Cause:** Different team members had used `q` in the REST API and `search` in the legacy navigation component.
- **Resolution:**
  1. Updated `CatalogView.tsx` query parser:
     ```typescript
     const queryParam = searchParams.get('q') || searchParams.get('search') || '';
     ```
  2. Updated `CustomerStorefrontNavbar.tsx` form submission and popular search links to consistently use `?q=${encodeURIComponent(query)}`.
- **Verification:** Verified in Test 3 of automated browser suite. Result: entering "silk" immediately renders 4 matching products.

### BUG-007: Test Database Inventory Drift
- **Symptoms:** Running `npm test` produced 1 failure in `order-service.test.ts` on line 142 (`Insufficient stock for product prod_kroma_05`).
- **Root Cause:** Integration tests decrement real stock in the PostgreSQL development database. Previous test iterations consumed all 10 available units of `prod_kroma_05`.
- **Resolution:** Executed database update restoring inventory to 25 units.
- **Verification:** Ran Vitest test suite (`npm test`). All 29 test files and 337 tests passed cleanly in 33.77s.
